# `tester` agent

**Purpose:** write the failing tests before the code exists.
**Use when:** you have acceptance criteria and want tests first, or you want coverage added to a change.

**Change:** the test command and the test style rules for your project.
**Keep:** "do not write the implementation" and "confirm it fails first". A test that never failed proves nothing.
**Test:** give it a criterion. The new test must fail when you run it.
