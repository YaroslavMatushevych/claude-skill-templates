# `generate`

**Purpose:** make an output with the same shape every time, from known facts.
**Use when:** you want a plan, a spec, a summary, a pull request description or a message in a fixed format.

**Change:** the list under the **Shape** heading in the file. Replace the labels with the sections your output needs, and change the length limit.
**Keep:** the rules "do not interview" and "never guess, put gaps under Open questions", and the **Check** line in the list. An output with no check is a wish.
**Test:** run it after a real discussion. A new person should understand the output without asking you.
